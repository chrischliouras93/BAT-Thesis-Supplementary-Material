# Συμπληρωματικό υλικό πτυχιακής εργασίας

Το παρόν συμπληρωματικό υλικό συνοδεύει την πτυχιακή εργασία:

**«Πιλοτική Προσαρμογή της Σειράς Δοκιμασιών BAT (Beat Alignment Test) για την Αξιολόγηση της Ρυθμικής Αντίληψης και του Αισθησιοκινητικού Συγχρονισμού σε Εφήβους Σπουδαστές Μουσικής»**

## Περιεχόμενα

### Ηχητικά αποσπάσματα

Το ηχητικό υλικό είναι οργανωμένο σε δύο μέρη:

- **1ο μέρος:** 14 αποσπάσματα χωρίς μετρονόμο, αποτελούμενα από 2 παραδείγματα εξοικείωσης και 12 αποσπάσματα της πειραματικής διαδικασίας.
